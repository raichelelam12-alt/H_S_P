Objetivo del prototipo

Este software permite registrar una lectura cardíaca, visualizar el resultado y mostrar una alerta de demostración cuando el valor se encuentra fuera del rango configurado. En una versión futura se conectará con sensores, una aplicación móvil y una plataforma web.
